### Project Overview
Built an end-to-end e-commerce analytics pipeline transforming raw transactional data into actionable marketing intelligence.

### Key Highlights
* Joined multi-table transaction, customer, and product records using SQL aggregations.
* Compared rule-based RFM quantile segmentation against $K$-Means clustering optimized via the Elbow Method and log transformations.
* Evaluated clusters using a custom multi-metric Fitness Score to surface actionable customer behavioral insights.
