### Project Overview
Engineered an end-to-end Python ETL pipeline to ingest, clean, and analyze continuous meteorological data.

### Key Highlights
* Automated hourly ingestion of weather observations from the Open-Meteo API into a structured database.
* Performed SQL analysis on longitudinal temperature, humidity, and wind-speed patterns.
* Built an interactive Power BI dashboard tracking KPIs, city comparisons, and temporal trends.
